## What this file proves

The times in the table are the first push times recorded by GitHub for the private development repository. They cannot be checked from outside; they are given so that the order of events is on record. The independent anchor is this file's own commit time.

## How to check

## Notes

- The forecast file holds 3,478 forecasts: 1,739 domestic player-seasons of 2025-26, each for the EuroLeague and the EuroCup. It contains no 2026-27 statistic.
- The second forecast file holds 3,478 forecasts for the same player-seasons and destinations, made with a league table published in 2015. It contains no 2026-27 statistic and is scored in the same single run as the first.
- The league-change file holds one prediction for each of 3,423 changes of domestic league by 1,649 players (seasons 2015-16 to 2025-26). It contains no performance rate of the season after the change; two yes/no columns record that season's games counts (at least 15 games in both seasons; a second domestic league in either season). It belongs to a second test, on past seasons, and is separate from the frozen 2026-27 test.
