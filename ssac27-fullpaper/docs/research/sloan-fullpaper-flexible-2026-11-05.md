## The question

The paper's league-aware model uses one number per source league. A judge may ask whether a richer model — the full box-score profile, age, minutes and the quality of the player's club — does better, and whether translation starts to matter inside such a model. E16 answers both with one fixed configuration and no tuning.

## In plain words

* **The flexible model is not detectably better than the league-aware model.** The gain is -0.108 EFF/36 (95% interval [-0.222, 0.005]): the point estimate favours the league-aware model, and the interval includes zero. With this sample a gain of 0.162 EFF/36 would be detected with 80% power.
* **Share of avoidable error removed.** Of the 0.913 EFF/36 of error that is avoidable in principle (history-only error 3.096 minus the noise floor 2.183), the league-aware model removes 18.8% and the GBM removes 7.0%.
* **A linear model with the same features.** The ridge on all the features lands close to the league-aware model: gain -0.019 EFF/36 (95% interval [-0.090, 0.052]; spans 0), removing 16.8% of the avoidable error.
* **Translation inside the flexible model.** Adding the translated feature z to the GBM lowers its error by 0.027 EFF/36 (95% interval for the gain [-0.027, 0.081]; spans 0; 80%-power detectable effect 0.077), so translation adds nothing detectable once the flexible model knows the leagues. The upper end of that interval is 2.66% of the GBM's error, above the paper's 2% margin.
* **Club quality.** Adding the source club's domestic win share to the ridge lowers its error by 0.002 EFF/36 (95% interval for the gain [-0.022, 0.025]; spans 0; 80%-power detectable effect 0.034).

How the club win share joins: Proballers player rows and game files spell clubs differently (sponsor names), so a plain name join reaches only 66.0% of the targets. Each player-row club is therefore linked to its game-file name through the games it played: in each game the club takes the side whose final score is closest to its players' summed points, and the most frequent game-file name wins. The lowest agreement among the targets' links is 45.5%; 0 links were dropped as ambiguous and 0 tied game scores were not counted as results. Only source seasons 2015–2024 are read (200 files).

## Choices the amendment did not fix (disclosed)

* **Club linkage.** The amendment names Proballers game files as the source of club win share but not the linkage; the game-based linkage above was used because a plain name join reaches far below the 90% gate. Win share = wins ÷ decided games in the club's source league-season file (regular season and play-offs as recorded).
* **Missing values.** A missing age is set to the centre (26) with an indicator, as registered. No club win share is missing in the cohort; had one been, it would have been set to 0.5 with an indicator.
* **Ridge details.** Columns are standardised with the training fold's mean and SD; the translated feature z counts as a non-history term and is penalised; columns constant in a training fold are dropped; source-league categories are the training fold's (as in v10). The GBM uses the raw (unstandardised) columns.
* **Software.** scikit-learn 1.9.0 in the run environment.
