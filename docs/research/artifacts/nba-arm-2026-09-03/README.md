# NBA arm — committed summary

corpus), re-run 2026-09-06 to a committed path; every number in `docs/research/nba-arm-result-2026-09-03.md`
reproduces. The per-player outputs (`nba_arm_scored.parquet`, `nba_moves.parquet`, `p2_chain.csv`) carry
NBA rows and are not committed (NBA.com terms of use §9).
